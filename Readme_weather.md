🌦️ Веб-приложение для анализа погодных данных

Веб-приложение для интерактивного анализа и визуализации исторических метеорологических данных.
Описание

Это веб-приложение позволяет:

    загружать данные из базы данных SQLite;
    исследовать данные с помощью интерактивных графиков;
    сравнивать погоду в разных городах;
    строить простые прогнозы на основе скользящего среднего.

Возможности приложения

Интерфейс разделён на вкладки для удобной навигации:

ДанныеПросмотр отфильтрованной таблицы с погодными данными. Можно показать все строки или только первые 10.

Разведочный анализ (EDA)Исследование распределений признаков (температура, осадки, ветер) с помощью гистограмм и диаграмм размаха (boxplots). Также доступна диаграмма рассеяния.

Сравнение городовСравнение динамики погоды по месяцам для выбранных городов. Визуализируются средняя температура, сумма осадков и скорость ветра.

Временные рядыОтображение динамики любого выбранного показателя во времени на интерактивном линейном графике.

ПрогнозированиеПростой прогноз на основе скользящего среднего. Пользователь задаёт окно усреднения и количество дней для прогноза.

    Важно: для работы этой вкладки в фильтре слева должен быть выбран ровно один город.

Управление фильтрами

Все настройки анализа находятся в боковой панели:

    Выбор города(ов): выберите один или несколько городов для анализа.
    Диапазон дат: укажите начальную и конечную даты периода, который вас интересует.
    Дополнительные фильтры: раскройте спойлеры, чтобы отфильтровать данные по категориям температуры (например, холодно/жарко) или уровню осадков.

Начало работы
Требования

Для работы приложения необходимо установить:

    Python версии 3.8 или выше;
    библиотеки: sqlite3, streamlit, pandas, numpy, plotly.

Установка зависимостей

Рекомендуется использовать виртуальное окружение для изоляции зависимостей проекта.
Создание виртуального окружения
bash
Копировать

python -m venv venv

Активация окружения

Для Linux/macOS:
bash
Копировать

source venv/bin/activate

Для Windows:
bash
Копировать

.\venv\Scripts\activate

Установка библиотек
bash
Копировать

pip install streamlit pandas numpy plotly

Подготовьте данные

Приложение ожидает файл базы данных SQLite по пути data/weather.db.

    Создайте папку data в корне вашего проекта.
    Поместите файл weather.db внутрь папки data.
    В базе данных должна быть таблица weather со следующими колонками (минимальный набор):
        date (DATE или TEXT в формате YYYY-MM-DD) — дата;
        city (TEXT) — название города;
        avg_temp (REAL) — средняя температура;
        total_precip (REAL) — общее количество осадков;
        avg_wind (REAL) — средняя скорость ветра.

Запуск

После установки всех зависимостей запустить приложение очень просто.

    Откройте терминал или командную строку.
    Перейдите в директорию, где находится файл вашего приложения (например, app.py).
    Выполните команду:

bash
Копировать

streamlit run app.py

    В терминале появится сообщение о запуске сервера. Скопируйте предоставленную ссылку (обычно http://localhost:8501) и вставьте её в ваш браузер.
