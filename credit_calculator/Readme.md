Кредитный калькулятор на Streamlit

Цель — реализовать собственный кредитный калькулятор.

Создано приложение на Python с использованием streamlit, 
которое будет обладать следующим функционалом:

*считывание суммы кредита

*процентной ставки

*срока кредита 

*типа платежа по кредиту (аннуитетный и дифференциальный); 

*вычисление ежемесячного платежа по кредиту (для аннуитетного типа);

*формирование графика платежей по кредиту в виде таблицы со следующими столбцами:

остаток долга

ежемесячный платеж,

процентная часть

долговая часть

остаток долга на конец периода;

*Дополнительно (факультативно):

*считывание даты первого платежа 

*обработку случаев неправильного ввода;

*использование механизмов условного рендеринга (if/else, st.expander() и st.stop()).
