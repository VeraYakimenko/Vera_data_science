📊 Анализ CSV-файлов

Веб-приложение для интерактивного анализа данных в формате CSV. Позволяет быстро визуализировать данные, строить графики и получать статистические показатели без необходимости писать код.

Описание

Программа представляет собой инструмент для первичного анализа данных, написанный на языке Python с использованием фреймворка Streamlit. Основная цель — предоставить удобный интерфейс для работы с табличными данными.

Алгоритмы и логика работы:

    **Автоматическое определение кодировки: Для корректного чтения файлов, созданных в разных операционных системах (Windows, Linux), 
    используется библиотека charset-normalizer. Она анализирует байты файла и выбирает наиболее вероятную кодировку, что предотвращает появление нечитаемых символов.
    **Определение типов данных: При загрузке данных программа анализирует каждый столбец с помощью методов библиотеки Pandas (pd.api.types).
    Столбцы классифицируются на:
        Числовые (numeric): Используются для построения графиков и расчета статистики (среднее, медиана).
        Категориальные (categorical): Используются для группировки данных и раскраски точек на графиках.
        Дата и время (datetime): Используются в качестве оси X для построения временных рядов.
    **Статистический анализ: Для выбранного числового столбца вычисляются базовые описательные статистики по выборке:
    **Визуализация: Построение интерактивных графиков с помощью Plotly Express. Доступны:
        Линейный график: Отображает зависимость Y от X. Если ось X является датой, данные сортируются по времени для корректного отображения тренда.
        Диаграмма рассеяния (Scatter): Показывает распределение точек в двумерном пространстве, позволяя выявить корреляцию между переменными.
        Гистограмма: Визуализирует распределение частот значений в одном числовом столбце. Пользователь может изменять количество интервалов (bins).
Установка зависимостей
Для работы приложения необходимо установить Python (версии 3.8 или выше) и все библиотеки, указанные в файле requirements.txt.

    *Создание виртуального окружения (рекомендуется):Это позволит изолировать зависимости проекта от других программ на вашем компьютере.
    python -m venv venv
    # Для Linux/macOS:
    source venv/bin/activate
    # Для Windows:
    .\venv\Scripts\activate

    *Установка пакетов:Выполните следующую команду в терминале после активации виртуального окружения:
    pip install -r requirements.txt
Запуск
После установки всех зависимостей запустить приложение очень просто.

    *Откройте терминал или командную строку.
    *Перейдите в директорию, где находится файл вашего приложения (например, app.py).
    *Выполните команду: streamlit run app.py
    *В терминале появится сообщение о запуске сервера. Скопируйте предоставленную ссылку (обычно http://localhost:8501) и вставьте её в ваш браузер.
